Before You Begin: What You Need

A quick checklist and key info to make Firestick setup smooth.

Beginner starter checklist

This page is here to help you figure out what you need before starting, what the setup involves, and where to jump to if you are not starting from scratch.

What this setup is going to involve

If you are setting up from the beginning, you will normally:

  • Complete the initial Firestick on-screen setup
  • Enable the settings needed to install apps outside the Amazon Appstore
  • Install Downloader so you can install AIO apps using a code

Before you start (quick checklist)

Make sure you have:

  • Your Firestick plugged in and turned on
  • A stable Wi‑Fi connection (and the password)
  • Your Amazon account signed in
  • Your AIO login details ready
  • About 10 to 20 minutes to complete setup

Compatible devices

These guides are written for:

  • Amazon Fire TV Stick (including 4K and 4K Max)
  • Amazon Fire TV / Fire TV Cube

If you are not starting from a fresh install

If your Firestick is already set up and you only need a specific step, jump straight to the guide you need:

  • First time setup (TV, remote, Wi‑Fi, Amazon sign-in): Setting Up Your Firestick
  • Need to allow installs outside the Appstore: Enabling Developer Options
  • Need Downloader installed: Installing Downloader

Important notes

  • Some steps require installing apps outside the Amazon Appstore.
  • Only use the official Downloader codes and links provided in this Help Centre.

Common quick fixes (if you get stuck)

  • Restart your Firestick: hold Select and Play/Pause for 5 seconds.
  • If an app freezes: try a quick restart first, then use Force Stop & Clear Cache/Data.
  • If you are low on storage: delete unused apps to free up space.
