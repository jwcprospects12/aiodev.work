VLC Player Playback Fix

Improve movie and series playback by installing VLC Player and adjusting AIO TV settings.

If you are seeing buffering, freezing, or stuttering during Movies & Series playback, using VLC as an external player can improve playback on some Firesticks.

This guide shows you how to install VLC, then select it inside AIO TV.

What is VLC Player?

VLC is a free media player that supports a wide range of video formats. When AIO TV uses VLC for playback, it can sometimes run more smoothly than the default player.

Before you start

  • This is recommended for Movies and Series only.
  • Do not set Live TV to VLC.

Quick instructions

  1. Install VLC from the Amazon Appstore.
  2. In AIO TV, open Settings.
  3. Go to External Players and add VLC.
  4. Go to Player Selection and set Movies and Series to VLC.

Final check

  • Play a Movie or Series and confirm VLC opens.
  • If VLC does not open, go back to Player Selection and confirm Movies and Series are set to VLC.
  • If playback is still poor, restart your Firestick and try again.

If you are still having problems after this, please contact support with:

  • The title you were trying to play
  • Whether VLC opened or not
  • What happened on screen
